Question Your Oracles

Validation Clarity Radar · August 13, 2026

This week's throughline: as agents make code and tests cheap, all the value moves to verification you can actually trust - from benchmarks agents have saturated, to making machine-written tests meaningful, to mutation testing as the metric with teeth, and the rise (and risks) of the AI judge.

In this episode:

  • OpenAI: Introducing SWE-bench Verified (the human-validated 500-issue benchmark agents are now saturating) — 2024-08-13
  • SWE-bench - leaderboard and the harder 'Pro'/live successors
  • Meta: Automated Unit Test Improvement using LLMs (TestGen-LLM - generate cheaply, filter ruthlessly) — 2024-02
  • Stryker Mutator - mutation testing for JavaScript and .NET
  • PIT (pitest) - mutation testing for the JVM/Java
  • Judging LLM-as-a-Judge with MT-Bench (documents position & verbosity bias in AI judges) — 2023-06
